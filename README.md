 # Runner Game / Darkest Run

Jeu de type runner développé en HTML, CSS et JavaScript.

## 🎮 Objectif
Éviter les obstacles, survivre le plus longtemps possible et faire le meilleur score.

## 🕹️ Contrôles
- Espace / ↑ : Sauter (double saut possible)
- ↓ / S : S’accroupir
- Mobile : tap pour sauter, glisser vers le bas pour s’accroupir

## ⚙️ Fonctionnalités
- Score basé sur la distance
- Vies (3 au départ)
- Difficulté progressive
- Obstacles variés (sol / vol)
- Effets visuels (particules, flash dégâts)
- Menu + Game Over

## 📁 Fichiers principaux
- index.html
- style.css
- game.js
