# Runner Game 

## Description
Runner Game est un petit jeu de type "runner" réalisé en HTML, CSS et JavaScript.  
Le joueur doit sauter ou s’accroupir pour éviter des obstacles et survivre le plus longtemps possible.

## Fonctionnalités (version 1)
- Personnage jouable
- Saut (ArrowUp)
- Accroupissement (ArrowDown)
- Génération d’obstacles
- Score en temps réel
- Meilleur score enregistré (localStorage)
- Écran de démarrage
- Game Over avec bouton rejouer
## Technologies utilisées
- HTML
- CSS
- JavaScript
## Comment jouer
- Appuyer sur **Commencer**
- Utiliser ↑ pour sauter
- Utiliser ↓ pour s’accroupir
- Éviter les obstacles

## Lancer le jeu
Ouvrir simplement le fichier `index.html` dans un navigateur.
